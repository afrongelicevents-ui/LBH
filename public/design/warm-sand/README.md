# LBH design: Warm Sand (approved)

Approved app-style design for letsbuildhome.co.zw. Open `index.html` in a browser (or `/design/warm-sand/index.html` on a Vercel preview) to see and click through it.

## Theme
Light (default when the phone is in light mode) and dark (when the phone is in dark mode), with a manual toggle.

| Token | Light | Dark |
|---|---|---|
| Background | #F1ECE5 | #17120E |
| Cards / panels | #FAF7F3 | #211A15 |
| Raised cards | #E6DCD0 | #2C231C |
| Main text | #2A1E16 | #F1E8DD |
| Soft text | #76675A | #B3A393 |
| Buttons / highlights | #B5552F | #D0703F |

Fonts: Playfair Display (headings), DM Sans (body).
